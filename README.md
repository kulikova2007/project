# Сайт личного стилиста — Анастасия Куликова

Учебный проект «Разработка пользовательского Web-интерфейса». Одностраничный сайт по **собственному макету** (задание разрешает свой макет аналогичной сложности). Стиль — нежный розовый «кукольный»: ворсистый фон, белые панели, барочная розовая рамка с бантом, каллиграфические буквицы. Стилистический референс лежит в `mockups/reference-style.jpg`.

## Структура

```
index.html        разметка
css/style.css     стили (mobile-first, брейкпоинты 600 / 1024 px)
js/main.js        заставка, меню, видео, лепестки на canvas, эффекты прокрутки, слайдер, форма
img/              SVG-иллюстрации: рамка, бант, сумочка, туфля, зеркальце, 8 «образов», портрет-заглушка, атлас, фон
video/            hero.mp4 (фоновое видео шапки) и hero-poster.jpg
mockups/          макеты для защиты: page.png, mobile.png, menu.png, mobile-menu.png, intro.png, reference-style.jpg
```

## Критерии задания

| Критерий | Где реализовано |
|---|---|
| Все блоки страницы | заставка, шапка с видео, «Обо мне», «Мой подход», «Опыт», «Услуги», слайдер «Образы», «Контакты» с формой, подвал |
| Мобильная версия | базовые стили для телефона, дальше `min-width: 600px` и `min-width: 1024px` |
| Видео в шапке | `<video autoplay muted loop playsinline>` с `poster`; видео смешивается с розовым фоном через `mix-blend-mode: multiply` |
| Выпадающее меню | «Обо мне» и «Услуги»: по наведению и фокусу, CSS-transition (`opacity`, `transform`, `clip-path`) |
| Мобильное меню | «занавес» на весь экран (`clip-path` + transition), пункты появляются по очереди, закрывается по Esc и клику на пункт |
| Шрифты | Cormorant Infant (заголовки), Great Vibes (буквицы), Montserrat (текст) — Google Fonts |
| Слайдер | 8 «образов»: 3 карточки на десктопе, 2 на планшете, 1 на телефоне; стрелки, точки, свайп и перетаскивание мышью, стрелки клавиатуры |
| Форма | проверка полей, блокировка кнопки и спиннер, сообщение об успехе/ошибке с просьбой отправить ещё раз, черновик в `localStorage`, отправка через `fetch` |

## Эффекты

- Заставка: рамка рисуется линией, появляются бант и имя; показывается один раз за сессию (`?nointro` — пропустить).
- Лепестки в шапке (canvas), останавливаются, когда шапка не видна.
- Блоки плавно появляются при прокрутке, счётчики «Опыт» набирают значение.
- Если в системе включено «уменьшение движения», анимации отключаются.

## Что поменять перед сдачей

1. **Фото.** Положите своё фото в `img/portrait.jpg` и в `index.html` замените `img/portrait.svg` на `img/portrait.jpg` (пропорции ~4:5).
2. **Тексты.** Цены, цифры в блоке «Опыт» и тексты услуг — примеры, замените своими.
3. **Ссылки** Telegram и WhatsApp в блоке «Контакты» (сейчас `https://t.me/` и `https://wa.me/`).
4. **Почта для заявок.** В `js/main.js` константа `RECIPIENT_EMAIL`. При первой отправке FormSubmit пришлёт на этот адрес письмо со ссылкой активации.
5. **Макеты.** Файлы в `mockups/` сняты без шрифтов Google (в среде не было интернета); переснимите их у себя в браузере.

Запускайте через Live Server или с хостинга (GitHub Pages), а не двойным кликом по файлу, иначе форма может не отправиться.
